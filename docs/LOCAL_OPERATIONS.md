# 本地运行保障

```sh
npm run ops:local                 # 单次只读检查和本地告警
npm run ops:local -- --watch      # 每 5 秒检查；不自动加载模型
npm run ops:local -- --watch --repair # 显式启用本次持久化基线的有限恢复
npm run demo:operations           # 在所选基线上执行实际故障与冷恢复验收
```

只监管 `.sites-runtime/local-baseline/current.json` 指向的专属持久化实例。生命周期命令具有进程互斥锁，拒绝并发启动、备份或升级；不会因等待超时破坏活锁。恢复沿用已有进程归属检查，最多十分钟内三次，超限记录人工处理告警。不会停止旧实例、未知端口或非本次拥有的进程。

告警写入 `.sites-runtime/local-baseline/alerts.jsonl`，最新状态写入 `operations-state.json`。状态相同不重复报警，故障、恢复、额度/授权不足、长期未决和死队列分别记录。不会发送外部消息或启动模型。进程可恢复不等于任何数据故障都可自动修复；预算、授权和 dead 队列需要 owner 显式处理，不通过重启扩权。

CCIP 每工作区最多 10 个未决任务、50 条保留记录；达到限制拒绝新建，不删除旧收据，不释放未决预算。业务容量 API 显示占用与 80% 预警。服务另外限制 1000 条任务历史；健康接口报告预算、日毛支出、授权到期和未决状态。已知预算或授权不可用时阻止新任务，已有任务仍可恢复和取消。额度不自动续期。

x402 供应商每 15 秒进行只读未决采购对账，RPC 不可用时继续保留占额；Feed 异常不阻止历史付款对账。它不产生签名、nonce 或新付款。只在 x402 服务运行期间启用，close 会清除定时器并等待本次对账结束。

实际 demo 校验：终止归属已核验的 CCIP 子进程 → 监管发现并恢复同一部署与交易 → 记录故障和恢复告警 → 停止后备份 → 在新目录启动冷恢复副本并核对原 Escrow 交易 → 停止副本并恢复所选基线。模型进程不是这个验收的必要条件。

备份与冷恢复沿用 [基线说明](LOCAL_BASELINE.md)，不会用新链覆盖旧历史。运行完整验收期间应暂停独立 watch 进程，避免它在有意停止进行备份时自动拉起服务。本地告警与短期监管验收不构成生产 SLA、宿主机断电/磁盘损坏恢复或真实网络验收。
