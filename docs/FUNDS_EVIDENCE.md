# 统一资金证据视图

钱包与托管页的“资金与未决证据”调用 owner-only 的只读 `GET /api/funds`。同一工作区展示沙盒积分、订单托管本金、CCIP 授权、供应商上游 token 成本和原生 gas；不将不同资产或资金责任相加。消费者凭证不能读取，跨工作区不返回订单/成本。

订单与供应商成本是已保存的检查点，显示凭证引用、状态与时间，不冒充本次实时回执复核。缺少收据或缺少成本记录时为 unknown/null，不能从用户已退款推断上游没有支出或释放供应商预留。CCIP 授权保持至结果和 ACK，退款本金与当天毛授权额度也不是同一个数。

页面另外读取主链及 CCIP A/B 的共享 Vault 余额；每个资金池分别记录链、token、Vault、精度及观测区块。共享余额不是该工作区独占、可提现或可授权额度；通道的预留也不能冒充链上不可撤销资金锁。RPC 不可用按池标为 unavailable，不展示零余额。API 不读取其他工作区的采购日志、不产生签名、授权、结算或退款。

供应商完整钱包级 gas/采购预留仍在其私有日志中；当前工作区没有可核验数额时显式显示未知，页面不估造数额。金额保留原始整数字符串，避免大整数原生费用经 Number 丢精度。

验证：纯投影边界测试、实际同工作区 CCIP/Feed/x402 组合故障投影、浏览器真实双链余额/预算/取消终态、跨工作区与消费者拒绝、中英文和移动布局。

付费插件逐步骤读取同 owner 的完整托管检查点；若主工作区引用与侧表版本不一致，标为不可用并保留引用中的授权，不使用错版本收据。混合、技能工作流、候选供应商和监测未来票据沿用既有预留选择器；交接后只显示子订单/插件的责任，不再重复显示父流程的未来授权。归档不删除已发生的资金历史。
